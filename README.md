# EV CARS in INDIA

## Fix 404 / "Page does not exist" on Vercel
1. Make sure `index.html` and `vercel.json` are in the **root** of your GitHub repository (not inside an extra nested folder).
2. If you uploaded them inside a folder (e.g. `ev-cars-in-india-vercel/`), go to Vercel -> **Project Settings -> General -> Root Directory** and set it to that folder name, then **Redeploy**.
3. Framework Preset: **Other** | Build Command: *(empty)* | Output Directory: *(empty)*.
